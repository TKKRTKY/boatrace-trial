# boatrace-trial

競艇の単勝プールに、統計モデルが市場を上回る余地があるかを確かめる**前向き試験**の記録です。

**実際に舟券は買っていません。** 賭け金はすべて仮想の100円で、レース終了後に公開データから
集計しているだけです。予想の提供でも、投資の勧誘でもありません。

## 何を試しているか

3年分の公開データで学習したモデルは、3連単市場には**負けます**（封印データ37,592レースで
log loss +0.031）。どの切り口で切っても、切り口自体を学習させても、勝てる区分はありませんでした。

一方で単勝プールは売り上げが薄く、モデルの本命を毎レース買うと回収率96.4%、市場の1番人気は
80.0%でした（単勝の払戻率は約74%なので、1番人気の80.0%はそれを上回る＝人気薄バイアス）。
ここから、

> 締切1〜5分前の実測単勝オッズで1番人気が一意に決まり、
> かつモデルの本命がその1番人気と違うとき、モデルの本命を100円買う

というルールを取り出したところ、モデルが一度も見ていない35,178レースで回収率106.2%
[103.3, 109.1] になりました。ただしこれは締切前の板を**再現**して得た数字です。

この試験は、**実測の板**で同じことが起きるかを確かめます。

## ルール

[PREREGISTRATION.md](PREREGISTRATION.md) に、開始前に凍結した全文があります。要点:

| | |
|---|---|
| 開始 | 2026-09-21 |
| 終了条件 | 10,000点 または 240日（早い方） |
| 主要評価 | 総払戻 ÷ 総仮想購入額 |
| 区間 | 日単位のクラスタブートストラップ（10,000回、seed固定） |
| 判定 | 下限>100%で確認 / 100%をまたげば保留 / 上限<100%で否定 |
| 賭け金 | 常に100円。調整なし |
| モデル | 試験期間中は固定 |

ルールは**対象レースが1件も存在しない時点で**文章に固定し、判定を左右するコード10ファイルを
指紋で凍結してあります。途中で条件を変えていないことは、この記録自体が証拠になります。

## 日次シート

<https://tkkrtky.github.io/boatrace-trial/>

各レースの「モデルの本命 / 市場の1番人気 / 買ったか / 1着 / 払戻」と、その日の回収率が並びます。

**日次の数字はほぼノイズです。** 1日約50点では95%区間が±40ポイント前後になるので、
良い日も悪い日も何も意味しません。だから各日の数字には必ず±を併記しています。
判定は終了条件に達した時点で一度だけ行います。

## 更新

毎晩、前日分が自動で追記されます。結果が公開された日から順に載るので、当日分は翌朝に出ます。
